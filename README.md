# GA4 Ecommerce Funnel Analysis

## Overview
This is a research project to find where customers drop out of the funnel onsite. 
It will use GA4 real-event data to view the rate of customer drop off in the funnel. 
SQL will be used for extracting, transforming and aggregating event 
data, and the findings will be visualised in an excel dashboard. 
The analysis will show opportunities and where to focus marketing efforts in the funnel.

## Research question
At which stage of the funnel (product view → add to cart → checkout → purchase)
do sessions on the Google Merchandise Store drop off most, 
and how does this vary by device category, traffic source and country?

## Data
Google's GA4 obfuscated sample ecommerce dataset (Google Merchandise
Store), accessed via BigQuery:
`bigquery-public-data.ga4_obfuscated_sample_ecommerce`
Period: November 2020 – January 2021.
